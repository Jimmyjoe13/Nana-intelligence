# Registre des Agents - Nana Intelligence SEO

Ce registre répertorie les agents virtuels spécialisés créés et mobilisés pour les tâches d'analyse, d'optimisation et de suivi du projet Nana Intelligence.

## 👥 Équipe Active

### 1. Auditeur Technique (Crawl)
- **Rôle :** Analyse les données brutes de crawl (ex: Screaming Frog) pour identifier les erreurs de statut, les problèmes d'indexation, les balises meta manquantes ou dupliquées, et les défauts de structure HTML (Hn).
- **Compétences :** Analyse de fichiers CSV de crawl, validation de balises canoniques, détection de boucles de redirection et de liens cassés.
- **Dernière activité :** Mobilisé le 2026-06-27 pour l'audit technique de Screaming Frog.

### 2. Analyste Performance & SEO (GA4/GSC)
- **Rôle :** Interroge les APIs Google Search Console et Google Analytics 4 pour récupérer les indicateurs de visibilité organique, de comportement utilisateur et de conversion.
- **Compétences :** Exécution de scripts Python, manipulation des API de données Google, extraction de rapports de positionnement et de taux de conversion.
- **Dernière activité :** Mobilisé le 2026-06-27 pour l'analyse GSC et GA4.

### 3. Orchestrateur SEO (Antigravity)
- **Rôle :** Conçoit la stratégie, supervise les agents spécialisés, croise les analyses techniques avec les données de performance, et rédige le plan d'action d'audit.
- **Compétences :** Synthèse stratégique, orchestration de sous-agents, diagnostic global et priorisation des correctifs.
- **Dernière activité :** Actif en continu.

### 4. Développeur Web & Intégrateur
- **Rôle :** Modifie le code source (React, Next.js, HTML) pour intégrer des tags, pixels et scripts de tracking, de SEO tiers ou de fonctionnalités d'optimisation.
- **Compétences :** Développement frontend Next.js, intégration de balises tierces, gestion du DOM et optimisation du rendu.
- **Dernière activité :** Mobilisé le 2026-06-28 pour l'intégration du script SEOJuice.
